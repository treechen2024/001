# 易經六十四卦互動式Web應用

一個功能完整的易經六十四卦在線查詢與互動工具，提供卦象展示、爻辭查詢、卦象變化等豐富功能。

## ✨ 功能特點

### 卦象展示
- 📊 完整展示六十四卦的卦象與爻辭
- 🎨 視覺化的卦象繪製：
  - 陽爻以**紅色實線**表示
  - 陰爻以**藍色虛線**表示
- 🖱️ **互動功能**：點擊爻線即可在陰陽之間切換

### 爻辭解讀
- 📖 傳統爻辭展示（來自易經經文）
- 💬 白話解說：點擊爻辭可查看現代白話解釋
- 📝 完整的六爻詳細注解
- 🔄 自動刷新：卦象變化時自動更新對應爻辭

### 卦象查詢與變化
- 🔍 **下拉選單快速選擇**：支援按卦序或卦名快速查找任意卦象
- 🔄 **錯卦功能**（黑色按鈕）：將所有爻的陰陽狀態反轉
- 🔁 **綜卦功能**（紅色按鈕）：將六爻順序上下顛倒

### 響應式設計
- 📱 完全響應式布局，支援各種屏幕尺寸
- 💻 適配桌面電腦、平板和手機等設備
- ⚡ 純前端實現，無需後端服務

## 🚀 使用說明

### 1. 查看卦象
```
- 打開應用後，默認顯示「乾為天」卦象（六陽爻）
- 使用下拉選單 (Select) 直接選擇特定卦象
- 支援按卦名或卦序快速定位
```

### 2. 修改卦象
```
- 直接點擊Canvas上的爻線可切換陰陽狀態
- 爻線自動在紅色實線（陽爻）和藍色虛線（陰爻）之間變化
- 實時顯示卦象變化時的爻辭內容
```

### 3. 查看爻辭
```
- 在右側爻辭容器中顯示六爻的傳統爻辭
- 點擊任意爻辭可展開白話現代解說
- 同時只展示一條爻辭的白話解釋
```

### 4. 卦象變化
```
按鈕說明：
- [錯卦] (黑色按鈕)：將當前卦象所有爻反轉（陰變陽，陽變陰）
- [綜卦] (紅色按鈕)：將當前卦象六爻顛倒（上下反轉）
```

## 💡 功能特色詳解

### Canvas 卦象繪製
- 從上到下依次繪製六爻（初爻在下，上爻在上）
- 每爻佔據 50px 高度
- 爻線寬度 160px，可點擊判定區域擴展至 30px
- 實時響應式繪製

### 爻辭同步更新
- 卦象變化時自動更新爻辭顯示
- 支援下拉選單、點擊爻線、錯卦、綜卦等所有操作
- 白話解說預加載，點擊時瞬間展開

### 智能選單排序
- 下拉選單按卦名進行中文排序
- 支援快速搜索（因瀏覽器 select 原生功能）
- 選單與卦象即時同步
