# 易經六十四卦 Web 應用

這是一個互動式的易經六十四卦網頁應用程序,讓使用者可以方便地查看和學習易經卦象。

## 功能特點

- 視覺化展示六十四卦的卦象
- 互動式操作:
  - 點擊爻線可切換陰陽
  - 下拉選單快速選擇卦象
  - 錯卦功能(陰陽反轉)
  - 綜卦功能(上下顛倒)
- 即時顯示:
  - 卦名
  - 爻辭
- 響應式設計,支援各種設備尺寸
- 清晰的視覺效果:
  - 陽爻以紅色實線表示
  - 陰爻以藍色虛線表示

## 使用方法

1. 直接在瀏覽器中打開 index.html 文件
2. 通過以下方式操作卦象:
   - 使用下拉選單選擇特定卦象
   - 點擊爻線切換陰陽狀態
   - 點擊「錯卦」按鈕將所有爻的陰陽狀態反轉
   - 點擊「綜卦」按鈕將六爻順序上下顛倒

## 文件結構

- `index.html`: 主要的HTML文件,包含頁面結構和樣式
- `yijing_data.js`: 包含易經六十四卦的爻辭數據

## 技術實現

- 純 HTML/CSS/JavaScript 實現
- 使用 Canvas 繪製卦象
- CSS Flexbox 實現響應式布局
- 原生 JavaScript 實現交互功能

## 瀏覽器支援

支援所有現代瀏覽器:
- Chrome
- Firefox
- Safari
- Edge
