# 易經六十四卦 Web 應用

這是一個互動式的易經六十四卦網頁應用程序,讓使用者可以方便地查看和學習易經卦象與爻辭。

## 功能特點

- 完整展示六十四卦的卦象與爻辭
- 視覺化的卦象展示:
  - 陽爻以紅色實線表示
  - 陰爻以藍色虛線表示
- 互動功能:
  - 點擊爻線可切換陰陽
  - 下拉選單快速選擇卦象
  - 錯卦功能(陰陽反轉)
  - 綜卦功能(上下顛倒)
- 爻辭解讀:
  - 顯示傳統爻辭
  - 點擊查看白話解說
- 響應式設計,支援各種設備尺寸

## 使用說明

1. 選擇卦象:
   - 使用下拉選單直接選擇特定卦象
   - 點擊爻線手動調整卦象

2. 查看爻辭:
   - 卦象變化時自動顯示對應爻辭
   - 點擊爻辭可查看白話解說

3. 卦象變化:
   - 點擊「錯卦」按鈕將所有爻的陰陽狀態反轉
   - 點擊「綜卦」按鈕將六爻順序上下顛倒

## 文件結構

- `index.html`: 主要的HTML文件,包含頁面結構和樣式
- `yijing_data.js`: 包含易經六十四卦的爻辭數據與白話解說

## 技術實現

- 純 HTML/CSS/JavaScript 實現
- Canvas 繪製卦象
- CSS Flexbox 實現響應式布局
- 原生 JavaScript 實現交互功能

## 瀏覽器支援

支援所有現代瀏覽器:
- Chrome
- Firefox
- Safari
- Edge

## 參考資料

本項目爻辭與解說參考自傳統易經典籍,經過整理編撰,僅供學習參考。
