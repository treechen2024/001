# 易經六十四卦 - 互動式卦象展示

這是一個基於網頁的易經六十四卦互動展示系統，讓使用者能夠直觀地學習和探索易經卦象。

## 功能特點

- **互動式卦象展示**：使用Canvas繪製清晰的卦象圖形
- **動態爻位切換**：點擊任意爻位可在陰陽之間切換
- **即時卦名顯示**：根據當前卦象自動顯示對應的卦名
- **完整爻辭展示**：顯示每一爻位對應的爻辭內容
- **響應式設計**：適配不同螢幕尺寸的顯示效果

## 技術實現

- 使用原生JavaScript實現互動功能
- HTML5 Canvas進行卦象繪製
- CSS Flexbox實現響應式佈局
- 模組化的數據結構設計

## 使用方法

1. 直接在瀏覽器中打開`index.html`文件
2. 點擊卦象中的任意爻位可以切換陰陽
3. 卦象變化時，右側會顯示對應的爻辭
4. 卦名會在下方自動更新

## 數據結構

- `yijing_data.js`：包含完整的六十四卦爻辭數據
- `index.html`：主要的展示界面和互動邏輯

## 開發說明

本項目採用純前端實現，無需額外的伺服器環境。所有的卦象數據都存儲在本地的JavaScript文件中，確保了快速的響應速度和良好的用戶體驗。

## 注意事項

- 建議使用現代瀏覽器（Chrome、Firefox、Safari等）訪問
- 確保JavaScript已啟用
- 保持`yijing_data.js`和`index.html`在同一目錄下
